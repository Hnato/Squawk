# Squawk Client

Uproszczona wersja frontu do Squawk.

## Co zostalo

- proste wejscie do gry po podaniu nicku,
- wybor koloru postaci,
- lokalna gra typu snake dzialajaca bez backendu,
- zapis wynikow w `localStorage`.

## Jak odpalic

```bash
npm install
npm run dev
```

## Sterowanie

- `WSAD` albo strzalki: ruch
- `Restart`: nowa tura
- `Wroc do panelu`: powrot do ekranu startowego
